# Research Note

I reviewed common CRM patterns from products such as Salesforce, HubSpot, and Pipedrive. The shared pattern is that sales users need quick access to pipeline status, contact details, notes, and follow-up activity. For this project, I kept the interface simpler but preserved the core workflow: a dashboard for overview, a client list for daily work, and a profile page for account settings.

The technical implementation focuses on JavaScript concepts required by the PRD: form validation, DOM rendering, events, arrays and objects, localStorage/sessionStorage, timers, fetch with async/await, and error handling. Because this is a frontend exam project, browser storage is used instead of a real backend.
